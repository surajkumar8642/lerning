`StudyPlanner` is a .NET 8 console application with xUnit tests. It is a small
example for practicing classes, validation, collections, LINQ, and unit tests.

```powershell
dotnet run --project projects/StudyPlanner/src/StudyPlanner
dotnet test projects/StudyPlanner/StudyPlanner.sln
```
